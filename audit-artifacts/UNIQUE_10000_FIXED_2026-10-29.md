# Fixed 10,000-case replay - 2026-10-29

Replay of the identical frozen 10,000 distinct-description API audit after the
software defects found at `c1c069e` were fixed. The **V3 model was not retrained,
no disease gate was relaxed, no threshold was changed**; the simulated-source
numbers below are byte-identical to the original run, which is the evidence that
the model selection path is untouched.

## Result

**10,000 / 10,000** distinct texts passed every declared software check
(original: 7,045 / 2,955 failed). Every category - routine, urgent, denial,
other-person, unsupported, mixed, contradiction, severe - had **0 failures**.
The 10 recorded immediate infant-fever bypasses and all 711 "no sense of smell"
false-absence cases are resolved. Outcomes: 2,664 prediction_complete, 5,754
assessment_uncertain, 1,582 urgent_review.

Full API and model status are in
[`unique-10000-fixed-2026-10-29/summary.json`](unique-10000-fixed-2026-10-29/summary.json);
every case is in the ignored `cases.jsonl` (not committed).

## What changed in the software (not the model)

- Shared negation scope: intrinsic loss/weakness wording ("no sense of smell",
  "no taste", "no energy", "no appetite", "sina nguvu") no longer negates a
  neighbouring symptom. The same context logic serves the independent safety
  detector, so infant fever is caught before routine mapping/questions.
- Old saved history now rechecks warning signs from the original description and
  age, including formerly missed infant fever.
- Discriminator "Yes" answers re-map and server-confirm the updated description
  instead of trusting stale local codes.

See [`AUDIT_FIXES_2026-10-29.md`](AUDIT_FIXES_2026-10-29.md) for the full list.

## Frozen V3 model, unchanged

`/model/status` reports `v3_partial_evidence`, 21 conditions / 34 features,
`covid_in_scope: false`, `clinical_validation: false`. Replayed strict
source check (existing DDXPlus test fold, 10,000 distinct full profiles, 9,958
distinct partial-model inputs):

- named selective accuracy **95.61% at 24.12% coverage** (eligible 2,412);
  correct name on 23.06% of all cases
- underlying model top-1 72.27%
- family answer on 484; 467 (96.49%) of those have a source class inside the
  declared viral family

These match the original run exactly. They are simulated-DDXPlus source
classification, **not** API triage and **not** Kenyan clinical validation.

## Not a clinical claim

This is a software regression replay: it shows the API no longer mis-handles the
previously failing phrasing and safety routes. It does **not** establish disease
accuracy, safety or comprehension for Kenyan patients. Clinical validation,
Kiswahili/Sheng comprehension testing and a real-world deployment study remain
required and were not performed here.
